# 萌芽学习小游戏

给孩子学中文的网页小游戏，手机、平板、电脑都能直接打开玩。

## 游戏列表

| 游戏 | 玩法 | 链接 |
|---|---|---|
| 拼音-英语配对 | 把拼音和对应的英语意思配成一对 | [开始玩](https://sproutlearning-lab.github.io/-/) |
| 汉字对对碰 | 点两个能组成词语的字，把它们消掉；可以自己添加词库，也可以拍照识别 | [开始玩](https://sproutlearning-lab.github.io/-/duiduipeng.html) |

## 新增游戏时

1. 把新游戏的 `.html` 文件上传到仓库。
2. 在上面的表格里加一行，链接写成：`https://sproutlearning-lab.github.io/-/` + 文件名。
3. 等一两分钟，网站自动更新后就能打开。
